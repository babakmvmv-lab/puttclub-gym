# PuttClub Gym

باشگاه بدنسازی آکادمی گلف پات‌کلاب — وب‌اپ (PWA) به سبک Apple Fitness، فارسی و راست‌به‌چپ.

- `index.html` — پوستهٔ سبک اپ (ورود با حساب آکادمی، خلاصه، تمرین، پیشرفت، من)
- `play/bench-press.html` — صحنهٔ سه‌بعدی پرس سینه (فقط هنگام پخش بارگذاری می‌شود؛ `?embed=1&p=m|f|g|t`)
- `sw.js` + `manifest.webmanifest` — نصب روی صفحهٔ اصلی و کش آفلاین
- `assets/` رندرهای خود صحنه · `fonts/` وزیرمتن (OFL) · `src/` سورس پوسته (`tools/build.py`)

داده‌های تمرین فعلاً روی دستگاه ذخیره می‌شوند؛ همگام‌سازی ابری پس از تأیید جدول‌های پایگاه داده.
