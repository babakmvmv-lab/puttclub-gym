# PuttClub Gym — پرس سینه (بدن هوشمند)

نمایش سه‌بعدی تعاملی حرکت **Barbell Bench Press** برای آکادمی PuttClub. شامل پروفایل‌های آقا، خانم و دختر و پسر نوجوان، نمای عضلات و دوربین سینمایی.

**مشاهده:** https://babakmvmv-lab.github.io/puttclub-gym/

- فقط یک فایل `index.html` مستقل است و منبع خارجی ندارد (حدود ۱۵ مگابایت).
- رندر WebGL2: پایپ‌لاین HDR، سایه‌روشن تماسی GTAO، سایهٔ تماسی، بازتاب محلی، DOF سینمایی و کیفیت تطبیقی.
